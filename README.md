# pairwise-dof

游戏过场动画切到景深后，角色头发边缘出现硬边，CoC 没有按深度做半分辨率扩散；bokeh 采样用固定圆盘，亮部高光变成方块；近景和远景 CoC 符号相反，合成时前景被糊到背景；透明粒子没有写深度，景深对它完全不生效；自动对焦在相机移动时追不上，焦点在两个人之间来回拉；HDR 高亮经过 DOF 后能量不守恒，画面整体变暗。postfx/dof.py 是核心，tests/test_dof.py 15个红。要修的是：按深度做 CoC 扩散；用多边形 bokeh 采样；分离近/远景并正确合成；透明物体用深度代理；自动对焦加阻尼和滞后；HDR 能量归一。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
